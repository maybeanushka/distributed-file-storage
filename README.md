# Distributed File Storage System



A fault-tolerant distributed file storage system that splits files into chunks, replicates them across storage nodes, verifies data integrity using checksums, and automatically recovers data when a storage node fails.



## Architecture



Client → Coordinator → Storage Nodes



## Planned Features



- File upload and download

- File chunking

- SHA-256 integrity verification

- Multiple storage nodes

- Data replication

- Node health monitoring

- Failure detection

- Automatic replica recovery

- Resumable uploads

- File versioning

- Storage monitoring dashboard
